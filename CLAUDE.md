# CLAUDE.md

## Проект

- Бэкенд: Go (`net/http`, `sqlx`, MySQL) — каталог `server/`, пакет `main`.
- Фронтенд: React + Vite + TypeScript — каталог `web/`.
- Запуск: `npm run dev` (Go API + Vite). Проверка типов: `npm run typecheck`. Сборка: `npm run build`.

## Главное правило: максимально просто и лаконично

- Пиши минимум кода, который решает задачу. Нет кода — нет багов.
- Никаких абстракций «на будущее»: интерфейсов, фабрик, обёрток, конфигов, generic-хелперов, пока они не нужны прямо сейчас хотя бы в двух местах.
- Предпочитай стандартную библиотеку. Новую зависимость добавляй только если без неё код станет заметно сложнее.
- Плоский код лучше вложенного: ранний `return`, без лишних `else`.
- Короткие функции, понятные имена. Не дроби код на мелкие функции без причины.
- Не дублируй логику, но и не выноси в общий хелпер то, что используется один раз.
- Комментарии — только когда «почему» неочевидно. Не пересказывай код.
- Не добавляй логи, валидацию, обработку ошибок и тесты сверх того, что реально нужно.
- Меняй только то, что просили. Без попутного рефакторинга, переименований и переформатирования.
- Пиши в стиле окружающего кода.

## Go

- Обычные функции и `http.HandleFunc`, без фреймворков и слоёв (handler/service/repository).
- Ошибки возвращай и обрабатывай сразу, без кастомных типов ошибок без нужды.
- SQL пиши прямо в коде через `sqlx`, без ORM.

## React / TypeScript

- Функциональные компоненты и хуки, без лишних библиотек состояния.
- Типы — простые, без сложных generic-конструкций.
- Стили и разметка — без лишних обёрток.
